# alerts

alerts 把巴西的官方洪水警报发送到 Discord。

- 版本 0 服务 3 个州：巴拉那州（PR）、圣卡塔琳娜州（SC）和南里奥格兰德州（RS）。
- 版本 0 使用 3 个数据源：Defesa Civil、INMET 和 CEMADEN。
- alerts 只使用官方数据源。

本项目处于初始化阶段。目前没有实现任何数据源。
