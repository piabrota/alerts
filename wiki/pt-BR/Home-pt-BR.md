# smart-alerts

O smart-alerts envia ao Discord alertas oficiais de inundação no Brasil.

- A versão 0 atende três estados: Paraná (PR), Santa Catarina (SC) e Rio Grande do Sul (RS).
- A versão 0 usa três fontes: Defesa Civil, INMET e CEMADEN.
- O smart-alerts usa somente fontes oficiais.

O projeto está na fase de bootstrap. Nenhuma fonte está implementada.
