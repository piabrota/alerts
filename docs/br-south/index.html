Extensões do Sul do Brasil

Estas páginas mostram como duas extensões funcionam dentro do AstrBot. As duas extensões são submódulos em forks/.

Estas páginas são uma prévia estática. Nenhuma página mostra um AstrBot em execução. Nenhuma página mostra um alerta real.

As duas extensões

CaminhoCommitO que a extensão entregaFontes
forks/br_south_disaster a667547 Alertas de inundação e de deslizamento, e alertas de chuva forte, em RS, SC e PR. CEMADEN, NOAA CPC
forks/br_south_waterq 12b71ac Mudanças de balneabilidade em RS, SC e PR. FEPAM, IMA, IAT

O nome do diretório é o id da extensão. O host exige esse nome e recusa o nome do repositório. Por isso, forks/ pode servir de raiz de extensões. Para baixar os submódulos, rode just forks-init.

As três camadas

  1. AstrBot: carrega plugins, chamados de Star.
  2. astrbot_plugin_disaster_warning: é o plugin, e é o host das extensões.
  3. br_south_disaster, br_south_waterq: são extensões. O AstrBot não conhece as extensões. Só o host conhece as extensões.

Estado do host

O sistema de extensões ainda não está em uma versão do host. O sistema está no PR #255, em rascunho. As duas extensões fixam o host em h0ffmann/astrbot_plugin_disaster_warning@2d2f261. As páginas descrevem esse commit.

O caminho até o alerts

O objetivo é que estes repositórios virem fontes do piabrota/alerts. Nenhum módulo do alerts lê os submódulos ainda. Esta seção é a análise do autor destas páginas. A seção lista o que a integração precisa resolver:

PontoFatoConsequência
Linguagem As extensões são Python. O alerts é todo em Haskell, com especificação em Agda, e o GROUND_TRUTH.md proíbe .py neste repositório. Os submódulos cumprem a regra, porque só o link fica aqui. O alerts não tem mais pacote Python: uma extensão lê o feed Atom com CAP 1.2.
CEMADEN O módulo Alerts.Source.Cemaden já lê os alertas do CEMADEN. br_south_disaster sobrepõe essa fonte. Os dois lados devem concordar sobre a mesma entrada.
Chuva forte A extensão calcula esse alerta com limiares próprios sobre os pluviômetros. Nenhum órgão emite esse alerta. A regra de fontes oficiais pede uma decisão humana antes de o alerts entregar esse alerta.
Balneabilidade O catálogo Alerts.Catalog não tem FEPAM, IMA nem IAT. Esta é a parte nova para o alerts. Cada órgão precisa de uma entrada no catálogo.
User-Agent O host cria a sessão HTTP sem cabeçalho próprio, e as extensões não definem um cabeçalho. Essas requisições não enviam Alerts.Core.userAgent. Uma fonte do alerts deve enviar esse valor.

Decisão: o alerts não embute um interpretador Python nem expõe um pacote Python. Uma extensão lê o feed Atom com CAP 1.2, com o mesmo texto do Discord. A lógica comum das duas extensões (o antigo módulo piabrota_alerts.ext) saiu com a implementação anterior ⚠: uma extensão que precisar dela mantém o próprio código.
