Configuração e status

O host não tem uma tela de extensões. O operador usa dois campos de configuração e um comando de chat.

Os dois campos

O grupo extensions do _conf_schema.json tem estes campos. O painel do AstrBot mostra os campos com o texto em chinês do esquema.

CampoRótulo no esquemaTipoPadrão
enabled_ids启用的扩展 ID 列表lista[]
settings扩展私有配置（JSON）texto JSON{}

Este exemplo ativa as duas extensões em português, só para SC:

{
  "enabled_ids": ["br_south_disaster", "br_south_waterq"],
  "settings": "{\"br_south_disaster\": {\"language\": \"pt-BR\", \"states\": [\"SC\"]}, \"br_south_waterq\": {\"language\": \"pt-BR\", \"states\": [\"SC\"]}}"
}

O valor de settings é texto. Um JSON inválido faz o host ignorar todas as configurações. O host trata o valor como {} e registra um aviso.

Configurações de cada extensão

ExtensãoChavePadrão
as duaslanguagezh-CN; outros valores: en, pt-BR, ja-JP
as duasstatestodas as UFs: RS, SC e PR
br_south_disasteralerts_interval300 s
br_south_disasterrain_interval300 s
br_south_disasterrain_thresholdsnível 2: 20 mm/1 h ou 50 mm/24 h; nível 3: 30 ou 100; nível 4: 60 ou 150
br_south_waterqpoll_interval21600 s

O comando de status

O comando /灾害预警扩展 é só para administradores. O texto abaixo segue o formato do código, com os ids e os nomes das duas extensões. Ninguém executou este comando para esta página.

Caso 1: as duas extensões carregam.
